一、如何开始

Web 原型版

  • 直接用浏览器打开项目中的 index.html。
  • 若需使用「云端账户」功能，请先在本机启动配套后端：
    node server/mock-server.js
    然后在「设置 → 高级」中确认「云端账户服务器地址」为 http://localhost:8787（留空即使用此默认值）。
  • 建议通过本地静态服务器打开（file:// 下部分浏览器会限制剪贴板 / Service Worker）：
    node serve.js   # 或任意静态服务器，指向本项目目录

Windows 桌面客户端

  • 安装后从开始菜单或桌面快捷方式启动。
  • 支持双击图片文件直接打开（文件类型关联）。
  • 支持右键图片 →「用绿角犀看图打开」（安装时写入系统右键菜单）。
  • 支持命令行启动：绿角犀看图.exe "图片路径"。

二、打开图片

方式说明
按钮「图片」选择一张或多张图片
按钮「文件夹」选择整个文件夹（按设置可递归子文件夹）
拖放将图片文件或文件夹拖入窗口
双击关联文件（桌面版）直接打开
命令行（桌面版）绿角犀看图.exe 路径

打开后，窗口中央显示第一张图，底部为缩略图栏（可按工具栏「缩略图」按钮或 Tab 隐藏/显示），右上角显示「当前序号 / 总数」。

三、看图基础操作

最近打开

  • 工具栏「🕘 最近」按钮（或空状态首页的「最近打开」区）记录最近打开过的文件夹与文件组，最多 12 条，按时间倒序。
  • 点击任意记录即可重新打开：桌面客户端（Tauri）用存储的完整路径经后端 load_paths 直接打开——文件夹递归载入、文件组精确重开原文件；Web 原型无持久路径，会提示并由你重新选择该文件夹/文件。
  • 每条记录右侧「✕」可单独移除；弹窗底部「清空记录」可一键清除。记录保存在本机 localStorage。

缩放与视图

  • 适应窗口 / 实际大小：工具栏「适应」按钮在两者间切换；双击图片同样在适应窗口与实际大小间切换。
  • 放大 / 缩小：工具栏 + / −，或快捷键 = / -，或鼠标滚轮（默认滚轮缩放，见设置）。
  • 滚轮行为：默认滚轮缩放、Ctrl+滚轮翻页；可在「设置 → 看图 → 滚轮行为」中互换为「翻页（Ctrl+滚轮缩放）」。

旋转与翻转

  • 左旋转 / 右旋转：工具栏按钮或快捷键 L / R。
  • 水平翻转 / 垂直翻转：快捷键 H / V。
  • 「设置 → 看图 → 记住旋转状态」开启后，翻页时保留旋转/翻转状态。

信息面板（EXIF）

  • 点击工具栏「信息」或按 I，右侧显示图片信息：尺寸、类型、大小、拍摄参数（EXIF，JPEG 自动读取方向并正向显示）等。
  • 面板底部「复制信息」可复制文本；按 Esc 或点关闭按钮收起。

复制图片到剪贴板

  • 快捷键 Ctrl+C（Mac 为 Cmd+C）将当前图片（含旋转/翻转状态）复制到系统剪贴板，可粘贴到聊天、文档等。

图片工具（滤镜 / 裁剪 / 导出）

  • 点击工具栏「工具」或按 E 打开图片工具弹窗，提供亮度、对比度、饱和度、灰度等滤镜调整，可实时预览并「重置」。
  • 裁剪：在预览图上拖拽即可框选保留区域；拖动选框四角可调整大小，在框内拖动可移动位置（带三分网格辅助构图）。点击「重置裁剪（全图）」取消裁剪。导出时会包含当前裁剪区域。
  • 导出 / 另存为：选择格式（JPG / PNG / WebP / BMP）与质量，导出结果会烘焙当前的旋转、翻转、滤镜与裁剪效果，下载到本机。

五、设为壁纸

点击工具栏「壁纸」可把当前图片设为桌面壁纸，提供 4 种模式（「设置 → 看图 → 设为壁纸模式」可设默认）：

  • 适应（留边）：等比缩放居中，留黑边。
  • 拉伸（铺满）：拉伸填满屏幕。
  • 居中：原始大小居中。
  • 平铺：以原图平铺。
Web 原型版无法写入系统壁纸，会按所选模式合成一张 1920×1080 图片并下载，用户手动设置；Windows 桌面客户端会直接设置真实系统壁纸。

六、批量处理

点击工具栏「批量」打开批量处理面板，对当前图片列表进行统一处理：

  1. 改尺寸：按宽度或百分比统一缩放。
  2. 嵌入 DPI（分辨率）：下拉选择 72 / 96 / 150 / 300 / 600，导出时在文件内写入分辨率信息——
    • PNG 写入 pHYs 块
    • JPEG 写入 JFIF 密度
    • WebP 写入 EXIF 元数据
  3. 导出：打包为 ZIP 下载；也支持逐张下载。
  4. 取消 / 报告：处理过程中可取消；完成后给出成功/失败报告。

七、收藏与浏览历史

这两项在云端账户模块中已建立本地存储，并可同步到云端（见第八节）。

收藏

  • 在图片上或工具栏点击「☆ 收藏」将当前图加入收藏；再次点击取消。
  • 打开「云端面板」（工具栏「☁ 登录」→ 已登录后进入；或单独收藏入口）查看收藏列表。
  • 登录状态下收藏会同步到云端；收藏列表中对已同步图片显示「☁ 已同步」徽标，并可下载该图片本体（跨设备还原）。

浏览历史

  • 每次成功显示一张图，自动记录到浏览历史（最多保留 50 条：图片名、来源路径、时间）。
  • 登录状态下历史同步到云端，多设备可续看。

八、账户与云端同步

绿角犀看图提供可选云端账户，登录后跨设备同步你的配置与数据。

注册 / 登录

  1. 点击工具栏「☁ 登录」，在弹窗中切换「注册 / 登录」。
  2. 注册：填写用户名、密码（至少 8 位）、昵称；登录：填用户名与密码。
  3. 登录成功后，工具栏显示账户状态，可打开云端面板。

同步范围

登录后自动同步以下四类数据（last-write-wins 冲突策略）：

  • 应用设置：快捷键映射、主题、壁纸模式、DPI 默认等。
  • 收藏记录：收藏的图片名、路径、加入时间（登录态收藏还同步图片文件本体，跨设备可下载还原）。
  • 浏览历史：最近打开的图片列表与时间戳。
  • 账户资料：昵称、头像、修改密码。

设置、收藏、历史的本地改动会在登录态下自动增量上传；登出前会做一次末次上传。未登录时所有本地行为完全不变、不触网。

服务器地址

  • 「设置 → 高级 → 云端账户服务器地址」：留空使用本地 mock（http://localhost:8787）。接你自己的真实后端时，填入其地址即可（接口契约见 server/mock-server.js 顶部注释：REST + JWT，端点含 /api/register /api/login /api/me /api/settings /api/favorites /api/history /api/favorites/image 等）。
安全提示：演示版 token 存于浏览器 localStorage；生产环境建议改用系统凭据保管（如桌面版的 keyring 插件）。

九、快捷键自定义

所有快捷键均可自定义（「设置 → 快捷键」或关于面板中的快捷键说明）：

  1. 进入设置 → 快捷键分组。
  2. 点击某动作右侧的按键按钮，按下新组合即可重绑；冲突的按键会自动让出。
  3. 「恢复默认快捷键」一键还原。

十一、触摸手势（触屏 / 移动端）

  • 单指拖动：平移图片（放大时）。
  • 双指捏合：缩放。
  • 双指滑动：翻页。
  • 其余操作与桌面一致（工具栏按钮同样可用）。

十二、PWA（Web 版安装到桌面）

Web 原型已启用 PWA：在支持的浏览器中，地址栏会出现「安装」图标，可将绿角犀看图安装为独立的桌面应用，离线可用、像原生程序一样从开始菜单/程序坞启动。

十三、Windows 桌面客户端专属能力

以下功能仅在 Windows 桌面客户端（Tauri 封装）中完整生效，Web 原型以对应 Web 能力替代：

能力说明
文件类型关联双击图片直接用绿角犀看图打开
右键菜单集成右键图片 →「用绿角犀看图打开」
系统托盘最小化到托盘、单实例（重复打开聚焦已运行窗口）
真实壁纸「设为壁纸」直接写入系统桌面
资源管理器定位在图片上右键「定位到文件」打开所在文件夹
系统剪贴板位图复制图片为系统剪贴板位图，跨应用粘贴

十四、常见问题

  • Web 版打不开/功能受限？ 建议通过本地静态服务器（如 node serve.js）打开，避免 file:// 下的剪贴板/Service Worker 限制。
  • 云端登录连不上？ 确认后端已启动（node server/mock-server.js），且「设置 → 高级 → 云端账户服务器地址」正确。
  • 某些格式打不开？ HEIC / RAW / TIFF / PSD 等需后端解码的格式，在桌面版由 Rust 解码后传入；Web 原型下浏览器原生不支持的格式会提示需桌面版。
  • 设置/收藏没同步？ 检查是否已登录；未登录仅存本地。登录态改动自动上传，也可在云端面板手动确认。
  • 想换回默认快捷键？ 设置 → 快捷键 →「恢复默认快捷键」。

    马赛克笔刷

    在预览图上按住涂抹即可打码；再次点击「退出马赛克」恢复正常操作。

    🩹 消除笔（内容感知填充）

    涂抹要消除的物体（文字/水印/路人），算法从周围纹理自动采样填充。纹理重复区域效果最佳。

    高级处理（OpenCV）

    首次使用需联网加载 opencv.js（约 8MB）；处理在导出时应用到最终区域。CDN 地址可在「设置 → 高级」修改。

    AI 放大（实验性）

    需联网加载 onnxruntime-web 与超分辨率模型（.onnx 地址在「设置 → 高级」配置，输入 1×3×H×W），导出时推理；实际倍率以模型输出为准。

    瘦身 / 瘦脸（局部液化）

    瘦脸：两侧脸颊向面中收缩；瘦身：身体两侧向内收。点「设定锚点」后在预览图上拖拽定位作用中心，作用范围按模式自动取形。

    ✨ 美型微调

    点按钮添加对应美型，再次点击撤销；右键按钮单独清除。支持多种同时启用。

    点「定位模式」后，点击按钮切换到该项目的锚点模式，然后在预览图上点击/拖拽确定作用位置。

    裁剪

    导出时会包含当前裁剪区域。拖动选框四角可调整大小，框内可移动位置。

    一键抠图（离线智能去背）

    点「前景笔」在要保留的主体上涂抹，「背景笔」在要去掉的区域涂抹，再点「✨ 一键抠图」生成透明蒙版。无需联网，边缘自动羽化；用「导出透明 PNG」保存带 alpha 的结果。

    未涂抹 — 先在前景/背景画笔中选择一种，在预览图上涂抹标记。

    导出 / 另存为

    导出会包含当前旋转 / 翻转 / 滤镜 / 锐化 / 裁剪 / 高级处理（OpenCV·AI）效果，下载到本机。

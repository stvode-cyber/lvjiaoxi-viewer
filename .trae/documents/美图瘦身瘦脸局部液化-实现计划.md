# 计划：美图「瘦身 / 瘦脸」局部液化形变

## Context（为什么做）
用户希望在现有美图能力中新增「瘦身 / 瘦脸」。这是**几何形变（液化）**类功能——不是改像素颜色，而是改像素**位置**，把脸颊/身体两侧向锚点收缩。它与现有「滤镜微调 / 磨皮 / 美白 / 抠图」都不同，因此需要新增一套「局部位移场 + 反向映射 + 双线性采样」的形变引擎，并接入现有的「预览=所见即所得、导出一致、支持 Ctrl+Z 撤销」管线。

## 目标交互（已按推荐默认确定）
- **统一液化工具**：强度滑块 + 可拖锚点 + 作用范围。瘦脸=小半径椭圆高斯区，瘦身=高垂直带形区，同一引擎两套参数。
- **定位方式**：强度 / 半径滑块 + 在编辑预览图(`#editPreview`)上**拖拽锚点**（复用 `onPreviewDown/Move/Up`）。
- **控件位置**：「高级」pane（`data-pane="pro"`），新增「瘦身 / 瘦脸」分区。

## 形变算法（核心 `slimWarp`）
以**水平向中间方向收缩**、作用随到锚点距离做二维高斯衰减：
```
对每个目标像素 (x,y)（归一化坐标）:
  dx = -K · w(x,y) · (x - cx)         // 向垂直中线收缩，两侧都向里
  dy = -Kv · w(x,y) · (y - cy)        // 可选竖直收缩（瘦身有轻微竖收）
  w  = exp( -((x-cx)²/rx² + (y-cy)²/ry²) )   // 二维高斯
  K  = strength/100 · 0.5              // 最大位移 ≈ 半程
src = (x - dx, y - dy)                 // 反向映射
目标像素取 src 处双线性采样（越界 clamp）
```
- **瘦脸**：`rx=ry=R`（如默认 0.22），近乎局部圆形，只让脸两侧往面中收。
- **瘦身**：`ry` 大（默认 0.55）、`rx` 小（默认 0.16），竖直带形，收身体两侧。
- 无像素环境（jsdom）按现有约定返回 `null`，预览/导出/测试自然降级。

## 落地改动

### 1. 状态与配置
- [app.js L318](file:///d:/源码存档/看图工具/app.js#L318) `state.filters` 旁新增：

### 2. 算法函数（app.js，放在 `sharpenCanvas`/`applyTone` 一带）
- `slimCanvas(canvas, slim) → canvas|null`：全尺寸导出用。读源 `getImageData` → 建目标 canvas → 逐像素反向映射 + 双线性采样（RGBA 各通道），失败返回 `null`。
- `applySlimInPlace(ctx, W, H, slim)`：预览用。与 `applyTone(ctx,W,H,f)` 同款：`getImageData` → 位移采样 → `putImageData`。**预览（缩放后小画布）与导出（全尺寸）用同一套位移场公式，保证所见即所得。**

### 3. 接入预览 / 导出
- 导出 [exportCanvasOfCurrent L1369](file:///d:/源码存档/看图工具/app.js#L1369)：`let full = bakeFullCanvas()` 之后、锐化/色调之前，若 `state.slim.enabled` 则 `full = slimCanvas(full, state.slim) || full`。
- 预览 [renderEditPreview L1986](file:///d:/源码存档/看图工具/app.js#L1986)：`ctx.drawImage(full,…)` 之后、`applyTone` 之前，加 `try { applySlimInPlace(ctx, canvas.width, canvas.height, state.slim); } catch(_){}`。
- 注：形变应先于像素质点（色）应用，位移不受色调整影响。

## 1. Nielsen 可用性启发式原则（10 条）

> 由 Jakob Nielsen 1995 年提出，至今仍是评估 UI/UX 的黄金标准。**任何评分低于 8/10 的原则 → 必须优化。**

| # | 原则 | 绿角犀看图里怎么判断 |
|---|---|---|
| 1 | **系统状态可见性** | 用户操作后有没有实时反馈？（toast / loading / 进度条）|
| 2 | **系统与真实世界匹配** | 按钮文字用的是大白话还是技术词？"LZW 压缩中" → "正在压缩" |
| 3 | **用户控制与自由** | 危险操作有没有撤销？（裁剪能不能撤销？）|
| 4 | **一致性与标准** | 快捷键风格统一吗？R 旋转 / H 翻转 / L 旋转 → 保持首字母 |
| 5 | **错误预防** | 能不能在用户犯错之前就拦住？（FPS 输入框 clamp 到 1-30）|
| 6 | **识别而非回忆** | 用户需要记住"海报标题在 decor tab 下面"吗？还是加个 banner 提示？|
| 7 | **灵活性与效率** | 能不能让高级用户更快？（快捷键 / 右键菜单 / 拖拽排序）|
| 8 | **简约美学** | UI 上有没有多余信息？（不必要的标题 / 空的 section）|
| 9 | **帮助用户识别/恢复错误** | 错误提示有没有下一步？"文件损坏" → "换一个试试" |
| 10 | **帮助与文档** | 有没有快捷键帮助页？（F1 或设置里）|

### 评分卡模板

```
原则 1 系统状态可见性:     8/10  ✅ toast + 进度条 → GIF 编码缺百分比显示
原则 2 系统与真实世界匹配: 7/10  ⚠️ "AI 超分" → "AI 高清增强" 更好
原则 3 用户控制与自由:     5/10  ⚠️ 裁剪不能撤销！P0 问题
原则 4 一致性与标准:       9/10  ✅ 全部快捷键首字母一致
原则 5 错误预防:           7/10  ⚠️ 大部分数字输入有 clamp → GIF 张数没上限
原则 6 识别而非回忆:       6/10  ⚠️ 部分功能藏太深 → poster 入口缺 banner
原则 7 灵活性与效率:       8/10  ✅ 全局快捷键可用 → 批量 GIF 缺快捷入口
原则 8 简约美学:           8/10  ✅ decor tab 分区清晰 → 证件照白边可隐藏
原则 9 错误提示恢复:       6/10  ⚠️ toast 缺下一步 → "文件损坏" → 没说怎么办
原则 10 帮助与文档:        5/10  ⚠️ 快捷键列表在设置里 → 应该 hover 显示
```

## 2. UX 反模式清单（20+ 条）

> **扫描时逐条检查，命中任何一条 → WARN 或 FAIL。**

### 2.1 信息架构类

| ID | 反模式 | 怎么判断 | 修复方向 |
|---|---|---|---|
| AM-01 | **层级过深** | 核心功能需要 ≥ 3 次点击才能到 | 提前到首屏 / 加快捷入口 |
| AM-02 | **平铺过载** | 一个 tab 里 > 5 个 section，视觉疲劳 | 分组 + 折叠次要 section |
| AM-03 | **命名晦涩** | 用技术词（"位移场" → "变形效果"）| 用户语言替换 |
| AM-04 | **无快速入口** | 功能只能从一个入口进 | 加 banner / 右键 / 快捷键 |

### 2.2 表单交互类

| ID | 反模式 | 怎么判断 | 修复方向 |
|---|---|---|---|
| FM-01 | **字段过多** | 同一操作需要填 ≥ 4 个字段 | 合并 + 一键预设 |
| FM-02 | **默认值愚蠢** | 默认值需要用户每次改（如 GIF 宽度默认 1280）| 分析最常见值做默认 |
| FM-03 | **无即时校验** | 输入非法值（负数 / 0 / 过长字符串）才报错 | 实时 clamp + 即时提示 |
| FM-04 | **不记得上次** | 用户关掉重开 → 重新填所有参数 | localStorage 记住上次值 |
| FM-05 | **高级设置暴露** | 普通用户能看到 LZW 算法选择 | 折叠到"高级"面板 + 默认隐藏 |

### 2.3 反馈类

| ID | 反模式 | 怎么判断 | 修复方向 |
|---|---|---|---|
| FB-01 | **无限 loading** | 操作卡住 → 用户不知道是慢还是死 | 加百分比 / 超时兜底 |
| FB-02 | **toast 没动作** | toast 只说"保存成功" → 下一步做什么？| 加"打开文件"按钮 |
| FB-03 | **错误只有技术词** | "OpenCV Exception" → 用户看不懂 | 翻译成大白话 + 下一步 |
| FB-04 | **静默失败** | 操作没反应 → 用户以为没点到 | 至少给个"无效"的反馈 |
| FB-05 | **进度不明确** | GIF 编码 → "正在处理" → 不知道还有多久 | 显示百分比 + 预计时间 |

### 2.4 一键化缺失类

| ID | 反模式 | 怎么判断 | 修复方向 |
|---|---|---|---|
| OC-01 | **参数分散** | 同一个"做 GIF"要跑 5 个参数 | 合并成"微信表情"预设 |
| OC-02 | **重复劳动** | 每次生成海报都手填"限时特惠" | 加一键示例 |
| OC-03 | **无智能默认** | AI 消除笔默认笔刷大小 5px → 用户每次改到 30 | 分析最常用值 |
| OC-04 | **确认多余** | 删除贴纸要"确定删除吗？" → 其实可以撤销 | 加撤销 + 减少弹窗 |

### 2.5 老年/无障碍类

| ID | 反模式 | 怎么判断 | 修复方向 |
|---|---|---|---|
| AA-01 | **字体太小** | font-size < 13px（最小可读）| 提到 14px |
| AA-02 | **按钮太挤** | 可点击目标高度 < 28px | 提到 32px |
| AA-03 | **对比度不够** | 前景/背景对比度 < 4.5:1（WCAG AA）| 加深颜色 |
| AA-04 | **动效花哨** | 无关动画 > 200ms | 删掉或减到 150ms |

## 3. 一键化机会识别规则

> **这是核心算法。** 把它翻译成代码思维就是：遍历所有参数组合 → 找"高频同现" → 生成预设。

### 3.1 规则清单

| 规则 | 触发条件 | 生成的一键按钮 |
|---|---|---|
| **R1 参数聚类** | ≥ 3 个参数总是一起被设置 | 合并成 1 个"场景"预设 |
| **R2 高频值** | 同一个参数值被 ≥ 70% 用户选中 | 设为默认值 + 生成该值的快捷按钮 |
| **R3 首屏入口** | 功能不在首屏 | 加 banner / 置顶 / 快捷键 |
| **R4 示例按钮** | 用户首次用该功能 | 加"生成示例"按钮预填参数 |
| **R5 历史记忆** | 用户上次的值 | localStorage 记住 + 自动恢复 |
| **R6 智能推荐** | 根据图片属性（尺寸/比例/数量）| 自动推荐最优参数 |

### 3.2 绿角犀看图当前一键化地图

| 功能 | 当前一键化率 | 机会点 |
|---|---|---|
| 证件照 | 20% | 标准一寸 A4 / 护照签证 / 小一寸 6寸照片 |
| 海报标题 | 40% | 限时特惠 / 新品发布 / 活动促销 / 美食推荐 |
| 边框 | 30% | 拍立得 / 复古 / 渐变 / 对角斜角（已有但藏太深）|
| GIF 制作 | 0% | 微信表情 480px / 短视频 720p / 表情包 320px |
| Logo 水印 | 30% | 右下角小 / 右上角大 / 平铺水印 |
| AI 消除笔 | 0% | 智能消除（默认 30px 笔刷 + smooth）|
| 批量加水印 | 10% | 版权水印 / 品牌水印 / 摄影师水印 |
| 美图调色 | 0% | 人像美化 / 风景增强 / 美食调色 / 黑白经典 |

### 3.3 一键化实施范式

```
范式 A：参数合并
  Before: FPS 10 + 宽度 480 + 画质 20 → 3 个下拉
  After: 「微信表情」按钮 → 一次性设好 3 个参数

范式 B：示例预填
  Before: 用户打开海报 → 标题空 → 副标题空 → 布局下拉 → 手动填
  After: 「一键生成示例海报」→ 预填"限时特惠/全场5折/price布局"

范式 C：首屏 banner
  Before: 海报藏在 decor tab 底部 → 用户找不到
  After: decor tab 顶部加粉色 banner「✨ 快速出海报（新手点我）」

范式 D：智能默认
  Before: 证件照白边默认 2mm → 用户经常改 3mm
  After: 统计 → 3mm 是高频 → 默认改成 3mm

范式 E：历史记忆
  Before: 上次用 GIF 10fps 480px → 这次重开 → 全部重置
  After: localStorage 记住 GIF 参数 → 自动恢复上次值
```

## 4. 黑盒测试流程模板

> **每次跑 UX 测试，按这个模板一步步走。**

### Phase 1：启动（0 分钟）

```
[ ] 启动 app → 记录首屏加载时间（目标 < 2s）
[ ] 截图首屏 → 有没有第一眼就知道"我能做什么"？
[ ] 空态提示检查 → 有没有指导用户"下一步"？
```

### Phase 2：打开 + 预览（1-2 分钟）

```
[ ] 点「图片」→ 选 1 张 → 成功预览？耗时？
[ ] 点「文件夹」→ 选文件夹 → 缩略图出来？耗时？
[ ] 点压缩包 ZIP/CBZ → 不解压直接看？
[ ] 放大 300% → 缩小 50% → 动画流畅？
[ ] 下一张 → 上一张 → 循环？
```

### Phase 3：核心编辑（3-5 分钟）

```
[ ] 亮度 +20 → 实时预览？需要 2 秒以上？
[ ] 加拍立得边框 → 能看到预览效果？
[ ] 加 emoji 贴纸 → 能拖动位置？
[ ] 生成海报 → 一键按钮能工作？
[ ] AI 消除笔 → 画一道 → 结果合理？
[ ] Logo 水印 → 上传 → 位置对吗？
```

### Phase 4：一键化扫描（5-8 分钟）

```
[ ] 逐功能区扫：证件照 / 海报 / 边框 / GIF / Logo / AI
[ ] 每个功能 → 数"需要手动设几个参数"
[ ] 如果 ≥ 3 个 → 识别为一键化机会
[ ] 输出机会清单 + 优先级排序
```

### Phase 5：异常狂点（8-10 分钟）

```
[ ] 空态点"生成海报"→ toast 提示？还是什么都没？
[ ] GIF 选 0 张 → 报错？还是静默？
[ ] GIF 选 200 张 → 有警告？还是直接卡？
[ ] FPS 输入 0 → clamp？还是 NaN？
[ ] 狂点"导出"→ 防抖？还是生成 5 份？
[ ] 打开损坏 ZIP → 友好提示？还是崩？
```

### Phase 6：老人视角（10-12 分钟）

```
[ ] 全局 font-size 扫描 → 有没有 < 13px？
[ ] 按钮高度扫描 → 有没有 < 28px？
[ ] 颜色对比度 → WCAG AA 4.5:1 过了吗？
[ ] 错误提示 → 全是大白话？
[ ] 快捷键 → 有没有给用户看的地方？
```

### Phase 7：输出报告（12-15 分钟）

```
[ ] 填充 Nielsen 10 原则评分卡
[ ] 扫描 UX 反模式清单 → 标注命中项
[ ] 一键化机会 TOP 5
[ ] P0 问题 → 修复方案
[ ] 对比上次得分 → 涨跌说明
[ ] 完整扫描清单 → PASS / WARN / FAIL
```

## 5. 专项测试手册

### 5.1 快捷键专项

```
[ ] 所有 18 个默认快捷键能按吗？
[ ] Esc 按顺序关弹窗（settings→batch→auth→cloud→about→info→return）
[ ] 改键后能持久化吗？（localStorage）
[ ] 冲突检测生效吗？（两个 action 绑同一个键 → toast）
[ ] 输入框里打字 → 快捷键不触发？
[ ] F1 快捷键说明页能用吗？
```

### 5.2 GIF 制作专项

```
[ ] GIF 编码中 → 进度条更新？
[ ] GIF 编码中 → abort 能取消吗？
[ ] 生成后 → 直接下载？
[ ] 文件大小合理？（480px / 10fps / 20帧 ≈ 1-3MB）
[ ] 能打开压缩包里的图片当帧吗？
[ ] 超过 200 张有警告吗？
[ ] 没图的时候点编码 → toast 提示？
```

### 5.3 证件照排版专项

```
[ ] 一寸 / 二寸 / 护照 → 5 种尺寸能选吗？
[ ] A4 纸上能排 49 张一寸 → 真的吗？
[ ] 自动裁源图比例 → 短边居中？
[ ] 白边可调 0-10mm → 实时更新？
[ ] 底色自定义 → 色盘能用？
[ ] 生成后 → 右下角有尺寸标注？
[ ] 裁切线灰色虚线 → 打印能看到？
```

### 5.4 老年体验专项

```
[ ] 全局 font-size 扫描（< 13px 的列表）
[ ] 按钮最小高度（< 28px 的列表）
[ ] 颜色对比度（前景/背景对）
[ ] 动效时长（> 200ms 的列表）
[ ] 错误提示大白话（技术词替换表）
[ ] 全局字号调大后会不会错位？
```

### 5.5 空态专项

```
[ ] 启动后没图 → 空态文案能指导下一步吗？
[ ] 批量面板空态 → "作用范围：全部 0 张" → 有意义吗？
[ ] 编辑 tab 空态 → 提示"先选择一张图片"？
[ ] 压缩包打开空包 → 提示"此压缩包无图片"？
```

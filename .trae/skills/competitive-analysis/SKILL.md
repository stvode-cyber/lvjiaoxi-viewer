# Competitive Analysis · 竞品分析方法论

## 分析框架

### Step 1：功能象限矩阵（4 维度评估）

| 维度 | 权重 | 评分 |
|---|---|---|
| **竞品出现频率** | 30% | 多少款竞品有这个功能（P0=5+ 款） |
| **用户痛点强度** | 25% | 去掉这个功能用户会不会流失 |
| **实现难度** | 25% | ⭐⭐⭐⭐⭐ 星数越低越优先 |
| **离线可行性** | 20% | 必须离线可运行（项目硬约束） |

### Step 2：分级

```
P0 必做：至少 3 款竞品有 + 难度 ⭐⭐⭐ 以下 + 离线可行
P1 次做：至少 2 款竞品有 + 难度 ⭐⭐ 以下
P2 差异化：1 款独家 + 难度 ⭐⭐⭐⭐ 以上但有高价值
跳过：需要云端 / 难度 ⭐⭐⭐⭐⭐ / 不是看图核心
```

## ✅ 已经实现（能做什么）

### 核心浏览
- 文件夹/单文件/压缩包直开，格式支持 JPG/PNG/GIF/HEIC/WebP/TIFF/TGA
- GIF 原生播动画 + decode_fallback 兜底（Iss-005 七次踩坑闭环）
- 压缩包内图片懒加载（ZIP/CBZ/RAR/7Z）
- 穿透文件夹递归扫描
- 左侧缩略图栏虚拟滚动窗口 ±3（最多 7 张 DOM + thumbUrl 永久缓存）
- 双击图片文件关联启动（Setup.exe ProgId 注册）
- 最近访问历史

### 性能
- rayon 并行 load_paths：53 张图 1500ms → 37ms（40-50x）
- IPC 懒加载：load_paths 只传元信息 + get_image_data 单张拉，冷启动 5.7s → 0.8s（7x）
- 毫秒时间戳日志（dbg_log，零成本线上工具）

### 美图编辑（内嵌底部栏）
- 美颜：滤镜微调 + 自动增强
- 风格配方：22 条预设（温柔青/暗黑胶片/韩系冷白...）
- 特效：边框+贴纸 / 海报标题 / 文字 / 马赛克 / 消除笔（Patch-Match Inpainting）
- 高级：抠图（高斯似然比+双边羽化≤512px）/ AI 超分（ONNX sub_pixel_cnn + ort.wasm，失败自动降级 Lanczos）/ OpenCV 降噪 / 裁剪
- 变形：合并位移场一次性双线性采样（导出=预览同公式）+ 美型微调（大眼/小脸/美牙/丰唇/瘦鼻）
- 海报：BORDER_PRESETS + emojiBar + 一键海报生成
- 批量处理：9 宫格平铺 -30° 水印 + 批量格式转换
- 切图编辑态全归零（每张图独立历史）

### 打包交付
- Tauri v2 + WebView2 离线运行时，单 EXE
- NSIS 全中文 SimpChinese 安装包，PreInstall 只留 taskkill
- EXE 静默启动托盘 + 单实例转发
- 版本号 7 落点自动化自检（scripts/check-versions.cjs）

### Android 主线（55%）
- 完整构建管线：`tauri android build --apk -t aarch64 armv7` 唯一入口
- Universal APK 35.38MB（arm64+armv7 release 签名）
- JNI 20 符号齐全 + 真机 PID 存活零崩溃
- AndroidManifest priority=100 绕过 Resolver 幽灵条目
- MainActivity pendingIntent 暂存 + allowContentAccess=true
- Manifest 9 个 intent-filter → 合并 1 个
- onNewIntent → __androidOpenFile 推给前端
- content:// SAF fetch 路径支持
- styles.css 移动端 @media(max-width:768px) 适配

### P2（竞品热门功能 · 2025-2026 Q4 调研落地路线图）

#### ⭐ S 级（低投入高感知，1-3h/个，**建议 v1.1.0 前完成**）

1. **长图滚轮翻页 + Webtoon 模式**
   - 对标：BandiView v8.03（刚出）+ FastStone + Skill long-image-scroll（现成方案）
   - 做什么：检测 height/width > 1.7 自动启用纵向 pan；滚到底自动翻页到下一张（Space/Shift+Space 快捷键）
   - 改什么：现有 showImage + mouse wheel 处理，新增 `longPan` 模式；左侧缩略图栏在 Webtoon 模式下隐藏
   - 依赖：零新依赖（纯 CSS flex + JS scroll）
   - 风险：低（只是滚动行为优化，不碰核心渲染管线）

2. **EXIF GPS 显示 + 地图链接**
   - 对标：HoneyView / FastStone（已有 EXIF 面板但缺 GPS 可视化）
   - 做什么：EXIF 面板加一行 `📌 GPS: 31.23°N, 121.47°E → 点击高德地图`（经纬度格式转换 + `https://uri.amap.com/marker`）
   - 改什么：app.js EXIF 渲染函数 + lib.rs decode_fallback 返回 EXIF 时一并传 GPS（已有 exifread）
   - 依赖：零新依赖（exif-rs 已在依赖里）
   - 风险：低

3. **深色主题**
   - 对标：全行业 2025+ 趋势（腾讯管家 18.1 / BandiView v7+ / 美图秀秀）
   - 做什么：styles.css 加 `.dark` 变量集（配色对齐浅色：背景 #1a1a1a / 文字 #e0e0e0 / 主色保持现有 accent）；顶栏加太阳/月亮按钮切换；`localStorage.theme` 持久化
   - 改什么：styles.css ~50 个选择器变量重映射 + app.js 一个 toggle 函数
   - 依赖：零新依赖
   - 风险：低（样式变量集中管理，改一处全局生效）

#### ★ A 级（中投入需架构，4-8h/个，**建议 v1.2.0**）

4. **SD Prompt 查看（PNG 元数据）**
   - 对标：BandiView v7.23+ / v8.03 新功能（"View prompts of images generated by Stable Diffusion"）
   - 做什么：Rust 端 png crate 读 tEXt chunk（参数名：parameters / prompt / negative_prompt / model / seed / steps）；前端 EXIF 面板下新增"🎨 SD 参数"tab
   - 改什么：lib.rs get_image_data 加 `.png` 时额外读 tEXt chunk；app.js 前端解析 + 渲染
   - 依赖：png crate 已在 Cargo.toml（零新增）
   - 风险：低（PNG 格式标准功能，纯读元数据）

5. **压缩包内 CBR/CBZ 双页视图**
   - 对标：HoneyView 核心功能 + Skill honeyview-archive-browse（现成方案）
   - 做什么：现有 read_archive_entry 单页浏览 → 加一个"漫画模式"按钮：双页并排（奇数左/偶数右）+ 最后一张空白页填充 + 翻页方向控制
   - 改什么：lib.rs 新增 `read_archive_double_entry`（一次传两张 data URL）+ 前端加双页布局
   - 依赖：零新依赖（zip crate 已在）
   - 风险：中（压缩包内图片可能跨目录，需要扫描相邻文件名）

6. **递归穿透文件夹**
   - 对标：HoneyView / FastStone / XnView 基础功能 + Skill recursive-folder-browse（现成方案）
   - 做什么：现有 load_paths 只扫当前目录 → 加一个"穿透子文件夹"开关 → Rust 端 `WalkDir` 递归收集所有子目录图片（已有 walkdir crate）
   - 改什么：lib.rs load_paths 加 `recursive: bool` 参数 + 前端顶栏加一个 toggle 按钮
   - 依赖：walkdir 已在依赖里（零新增）
   - 风险：低（已在 .gitignore 里加过 walkdir，说明之前用过）

## 🎯 核心卖点（对外可讲）

1. **合并位移场变形**：大眼/瘦脸/丰唇叠加不冲突，导出 = 预览像素级一致
2. **AI 超分失败自动降级**：ONNX 崩了 Lanczos 顶上，绝不挂起
3. **压缩包直看**：ZIP/CBZ 懒加载，不解压直接浏览
4. **GIF 四路径全闭环**：主图/压缩包/缩略图/底部缩略图，每条路径都有兜底
5. **rayon 并行 + IPC 懒加载**：50+ 张图双击几乎瞬间显示
6. **台账驱动**：跨 AI 30 秒接手即懂，版本号自检脚本一键验全落点

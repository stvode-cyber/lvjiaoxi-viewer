### 10-08 · GIF 无法解码兜底修复
- **根因链**：WebView2 对某些 GIF 变种/损坏文件原生解码失败 → lvjx-debug.log 5 张 GIF 全 CATCH broken
- **修复**：lib.rs NATIVE_EXTS 移除 "gif" → 三处解码入口（load_paths 行 419 / read_archive_entry / resolve_image_url）同步加 gif 走 image crate → JPEG
- **代价**：GIF 失去动画帧（image crate gif 解码只取第一帧）
- **回归测试同步**：regression.cjs 行 1203 源码断言字符串更新匹配
- **踩新坑**：NSIS /S 静默安装到自定义路径时不覆盖旧 EXE → 新修复不生效 → 必须手动 Copy-Item + Stop-Process + 验证 Hash（Iss-005 踩第 6 次）

### 10-08 · 单图打开后无法切换
- **诊断结论**：代码没 bug，是 IE 缓存子目录里的 0 字节空 GIF（IE 截断）被 image crate 正确跳过 → load_paths 只剩 1 张有效 PNG → 没法切下一张
- **验证**：gif_test.exe 解码正常 GIF ✅，解码 IE 缓存 0 字节 GIF ❌（EOF，预期行为）
- **结论**：用户需要用正常文件夹测试（含多张图）

## 本轮踩的所有坑（新 AI 别再踩）

### 坑 1：gradle 里 npm.bat not found
- gradle rust 插件（`rustBuildArm64Release`）调 `npm.bat tauri android android-studio-script`
- 机器上只有 `C:\Users\Administrator\AppData\Local\Programs\nodejs\npm.cmd`，**没有 npm.bat**
- gradle ProcessBuilder 硬找 `.bat` 扩展名 → 报错
- **修复动作**：我手动复制了一份 `npm.cmd → npm.bat`
  - 路径：`C:\Users\Administrator\AppData\Local\Programs\nodejs\npm.bat`
- 或者：在 gradle wrapper 里临时注释掉 rust 插件（我改了 build.gradle.kts）
- ⚠️ 下一轮记得还原 build.gradle.kts 的注释！

### 坑 2：manual cargo build 缺 mobile_entry_point JNI 符号（Iss-007）
- 手动 `cargo build --target aarch64-linux-android --release` + 手动拷 .so → APK 启动崩溃
- **根因**：`#[cfg_attr(mobile, tauri::mobile_entry_point)]` 宏只在 `tauri android build` 完整管线里触发 JNI 桥生成
- **铁律**：Android APK 构建**唯一正确入口** = `tauri android build --apk`
- 如果 npm.bat 问题没解决，临时绕过法：注释 build.gradle.kts 里的 rust 插件 → 手动 `gradle assembleRelease`（前提是 .so 已在 jniLibs）

### 坑 3：manifest `<priority>` 子元素写法 AAPT 不认识
- 我第一次写成 `<priority android:value="100" />` 放在 intent-filter 里 → AAPT 报错 "unexpected element <priority>"
- **正确写法**：`<intent-filter android:priority="100">`（属性，不是子元素）

### 坑 4：ResolverActivity 无法用 adb 清除 ghost 条目
- 试过：pm uninstall / pm clear-package-preferred-activities / settings delete preferred_activities / cmd package set-home-activity / pkill system_server
- 都没用。ghost 在 `/data/system/users/0/package-restrictions.xml` 里，非 root 读不到也改不了
- 只能靠 manifest priority 让 Resolver 跳过它

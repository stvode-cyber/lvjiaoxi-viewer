## 本轮踩的所有坑（新 AI 别再踩）

### 坑 1：Android force-stop 后 stopped=true（Iss-009）
- force-stop 后 `am start` 返回 "delivered to currently running top-most instance"，但进程不存在
- 根因：Android 12+ 安全机制，自动化启动不清除 stopped
- 解决：让用户手动点桌面图标启动一次

### 坑 2：armv7 交叉编译缺 clang.exe（Iss-008）
- `zstd-sys` C 依赖需要 NDK clang.exe，但 cc-rs 找不到
- arm64 没事，armv7/x86 会挂
- 解决：设 `CC_armv7_linux_androideabi = NDK/bin/armv7a-linux-androideabi24-clang.cmd` 或 NDK/bin 加 PATH

### 坑 3：tauri android build gradle 输出 pipe 问题
- 后台 gradlew.bat 的输出管道容易空日志
- 建议直接前台跑：`Set-Location src-tauri\gen\android; & .\gradlew.bat :app:assembleArm64Release`

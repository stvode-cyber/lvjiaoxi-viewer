# user-preferences.md · 用户行为偏好

> 记录在案，AI 每次新会话先读这个，避免反复踩"用户不喜欢"的坑。
> 最后更新：2026-10-17

---

## 沟通方式

- ✅ 大白话，像和同事聊天，不用技术黑话/论文腔
- ✅ 一次宣告全量动作，等一个 OK 就干完，不要每步停下来问
- ✅ 只做确认，不想手动操作，AI 全权搞定
- ✅ 回复用最简脑图代码格式（@startmindmap）
- ❌ 反复确认同一件事
- ❌ 输出一堆验收/运行指令让用户自己敲
- ❌ 替用户做业务决策（用户说啥就做啥）

## 功能选择原则

- 不考虑成本/工作量大小，只关注质量
- 选最强、最稳定的办法，不搞"凑活能用"
- 后端代码先思考"是不是一定要写"，要高效
- 前端要简洁易懂的操作体验

## 产品硬约束（不能碰的）

| 项 | 规则 |
|----|----|
| 美图面板 | 内嵌底部栏（border-top），**禁止**改成弹窗/浮窗 |
| 批量面板 | 遮罩弹窗（.batchMask），覆盖主图正常 |
| 导航条 | 顶栏 6 + bottom-nav 6，**不可**增删按钮 |
| 切图行为 | 所有编辑态归零，图片独立编辑历史 |
| 版本号 | 7 落点必须全同（tauri.conf.json / Cargo.toml / manifest / app.js about / sw.js CACHE / EXE FileVersion / EXE ProductVersion） |
| 打包 | 只交付 NSIS Setup.exe（全中文 SimpChinese），不要 Portable 绿色版 |
| 发版前 | 先本机静默安装验证 → 版本号 → 启动冒烟 → 卸载，通过后再推整体 |

## 发布/构建约束

| 项 | 规则 |
|----|----|
| PowerShell | 参数行纯 ASCII，中文注释单独 # 行（Iss-002） |
| 改前端后 | sw.js CACHE **必须 +1** |
| 打包前 | 跑 node scripts/sync-dist.cjs |
| Android 构建 | **唯一入口** tauri android build --apk，禁止手动 cargo build + 拷 .so（Iss-007）|
| NSIS | PreInstall 只留 taskkill，不做 RMDir /r（Iss-004）|
| Setup.exe 路径 | 必须通过 Setup.exe 覆盖安装更新文件关联，禁止手动 Start-Process release EXE（Iss-011）|

## UI 偏好

- 默认浅色主题
- 美图标签栏横向一行可滑动，禁止换行
- 顶部导航条扁平一行显示，不使用嵌套下拉
- 表格内容首行不要叠加，一行形式
- 美图面板展开在底部导航条紧上方，不是贴浏览器底部

## AI 工作流偏好

| 阶段 | 规则 |
|----|----|
| 启动 | 先摸家底：台账速读 + regression 全绿 + 版本号落点一致 |
| 动手前 | 宣告动作清单 → 等用户说"可以" → 再执行 |
| 执行中 | 一口气干完宣告的所有动作，不中途停下来问 |
| 执行后 | 总汇 5 行以内大白话说清干了啥 |
| 台账维护 | 改前必扫 issues.md 活跃坑 → 改完记 Chg/Iss → 会话结束总汇 |
| 台账瘦身 | 按主题聚合合并，目标 ≤15 条 Chg；踩够 3 次自动归档 |
